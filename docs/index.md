# EvoKit

Evolutionary search where the variation operator can be a one-shot LLM call, a headless
coding agent, or the coding agent you are talking to.

- [primitives.md](primitives.md): the pieces: types, components, storage, history, and `ask`, `evaluate`, `tell`.
- [recipes.md](recipes.md): one loop per published algorithm.
- [tasks.md](tasks.md): defining a problem as a task folder, and running it from the shell.
- [reading-runs.md](reading-runs.md): reading a run with `log`, `show`, `diff` and `grep`.

The README lists the open design work.
