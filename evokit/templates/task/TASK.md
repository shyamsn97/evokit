# Goal

Make `solve()` in `main.py` return a number as close to 3 as possible.

# Rules

- Edit only the genome files (`main.py`). `evaluate.py`, `config.yaml` and this file are fixed.
- `solve()` must take no arguments and return a number.

# Scoring

`evaluate.py` runs `solve()` and reports `score = -|solve() - 3|`. Higher is better; 0 is perfect.
A program that crashes or returns something other than a number fails its evaluation.

# Hints

- The evaluator's feedback says what `solve()` returned.
